System Architecture

NSTP Management & Grade Automation Platform

Presentation Layer (Client)
Coordinator Admin Portal
Unified dashboard for managing sections, tracking instructor workload, approving reports, and overseeing the entire NSTP program.
HTML5 Bootstrap 5 Vanilla JS
Instructor Workspace
Dedicated interface for instructors to manage their assigned CWTS/LTS/ROTC sections, submit grades, and upload activity logs.
Responsive UI Chart.js AJAX
Student View
Read-only access portal allowing students to view their NSTP status, retrieve digital certificates, and verify compliance.
Mobile First CSS Flexbox
Application Layer (Server)
Core Routing & Controllers
Processes HTTP requests, enforces role-based access control (RBAC), handles session management, and orchestrates business logic.
PHP 8 MVC Pattern Sessions
OCR Grade Engine (v3.2)
Automated processing module that parses uploaded physical grade sheets (PDF/JPG), extracts student scores, and digitizes records.
File Parsing Data Extraction Validation
Certificate Generator
Automated batch processor that evaluates passing criteria and generates official PDF completion certificates with unique serials.
Batch Processing Dynamic Generation
Data Layer (Storage)
Relational Database
Centralized storage enforcing schema integrity. Stores users, encrypted passwords, student rosters, hierarchies, grades, and audit logs.
MySQL PDO (PHP Data Objects) Relational Integrity
File Storage System
Local directory-based secure storage handling raw grade sheet scans, submission evidence attachments, and generated PDF certificates.
Local Filesystem Access Control
